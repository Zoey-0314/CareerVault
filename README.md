# CareerVault

> Tell your story once. Tailor it for every opportunity.

CareerVault is an AI-powered career memory and resume tailoring workspace. It helps users build a verified personal experience library, enrich each experience through guided AI follow-up questions, match relevant evidence to a job description, and generate a concise one-page resume without inventing achievements.

## V1 Scope

CareerVault V1 intentionally focuses on six core capabilities:

1. Personal profile
2. Experience library
3. AI-guided experience enrichment
4. Paste a job description
5. Job-to-experience matching
6. Generate a one-page resume

## Core Principle

**Facts are the source of truth. AI may reframe verified experiences for different roles, but it must never invent achievements, metrics, tools, responsibilities, or outcomes.**
